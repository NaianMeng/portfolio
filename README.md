# Naian Menginelli — Portfólio Hipercubo

Portfólio de Naian Menginelli, designer com foco em motion design, audiovisual e 3D. O hipercubo interativo funciona como menu e conecta as áreas de trabalhos, sobre e contato.

[Acessar o portfólio publicado](https://naian-portfolio.naianmenginelli.chatgpt.site/)

## Estrutura

- `dist/index.html` reúne a estrutura e o conteúdo do site.
- `dist/assets/` reúne estilos, scripts e mídias dos projetos.
- As páginas usam rotas por fragmento, como `#works` e `#project/fragmin`.

## Executar localmente

Na raiz do repositório, execute:

```sh
python3 -m http.server 8080 --directory dist
```

Abra [http://localhost:8080](http://localhost:8080).
